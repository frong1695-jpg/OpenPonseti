# OpenPonseti

OpenPonseti is an open-source modular monitoring platform for Ponseti Foot Abduction Braces.

The project explores how low-cost sensors and ESP32-based hardware can make brace use in everyday environments more observable, recordable, and understandable.

## Current Version

**OpenPonseti v0.1**

The current prototype focuses on:

- Heel contact / relative force sensing
- Brace connection detection
- Shoe temperature and humidity
- Brace movement sensing
- Local microSD data logging
- Wi-Fi data transmission

## Current Hardware

- ESP32
- FSR pressure sensors
- SHT31 temperature and humidity sensors
- MPU6050 IMU
- Hall sensors
- MicroSD card module

## Project Status

OpenPonseti is currently an early-stage research and design prototype.

The current development process starts with individual sensor testing and single-side bench testing before integrating the final dual-foot system.

## Important Notice

OpenPonseti is a research and educational prototype.

It is not a certified medical device and should not be used for diagnosis, treatment decisions, or clinical interpretation without appropriate validation.
